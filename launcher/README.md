# Dungeon Delve launcher

Download the complete Windows release from GitHub Releases and double-click
`Dungeon Delve.exe` inside its extracted folder. The custom portal icon also
appears on desktop shortcuts created by Setup. A small startup window closes
when the game opens; no command window is shown. If startup fails, read the
message, use **Choose Barony folder...** if necessary, then **Try again**.

The optional `Dungeon-Delve.exe` asset adds the same launcher to an existing
complete 0.17.2 installation. Save it beside that package's `Launch.ps1` and
`release.json`. The small EXE alone is not a playable game or an installer.

Windows x64, .NET Framework 4.5+ (included with Windows 10/11), an owned matching
Steam Barony installation, and the complete mod folder are required. Keep the
launcher, Launch.ps1, release.json, runtime and mod folders together. Read the
main PLAYER-GUIDE.md for installation, checksums, updates and troubleshooting.

These repository scripts are retained for compatibility and diagnostics.
The compiled EXE and full player packages are attached to GitHub Releases.
The original icon artwork is provided as PNG/ICO. Native and C# implementation
source is not included in this distribution repository.
